# Pannkaksrecept

En enkel och stilren webbplats som presenterar ett klassiskt recept på tunna pannkakor. Projektet är byggt som en statisk HTML/CSS-sida med fokus på tydlig layout, läsbar text och ett recept som är lätt att följa.

## Projektbeskrivning

Denna sida visar:

- En hero-bild med pannkakor
- En kort introduktion till receptet
- Ingredienser för fyra portioner
- Steg-för-steg instruktioner
- Serveringsförslag och bildgalleri

## Teknologier

- HTML5
- CSS3
- Lokal statisk webbsida utan backend

## Struktur

- `index.html` – huvudsidan med receptet
- `style.css` – stilmall för layout och design
- `image_c8d4ea.jpg` – använd bild för projektet

## Hur man kör projektet

1. Öppna mappen i en webbläsare.
2. Dubbelklicka på `index.html` eller starta en enkel lokal server om du föredrar det.
3. Se receptet i webbläsaren.
